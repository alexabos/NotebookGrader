Introducción a Python — Unidad 2: Ejercicios para entregar
Grading rubric (0–10 scale, total 10 points)

---

### Ejercicio 1 — Variables (1 point)
- a) Numeric variable `a = 2` (0.25 pts)
- b) String: "Me encanta la programación en Python" (0.25 pts)
- c) List of 12 months (Enero–Diciembre) (0.25 pts)
- d) Dictionary of 4 elements mapping a series name to number of seasons (0.25 pts)

### Ejercicio 2 — String manipulation (1.5 points)
Extract first name, surname, and birth year from the string "Rosalia Vila was born in 1992"
and print them. Award full marks for any correct approach (split, indexing, etc.)

### Ejercicio 3 — Palindromes (2 points)
- a) Demonstrate that "sobreverbos" is a palindrome (0.5 pts)
- b) Program that takes user input and checks if it is a palindrome (1 pt)
  - Note: `input()` will fail in automated execution — do not penalise for this specifically;
    check that the logic is correct
- c) Wrap the palindrome check in a function with the word as a parameter (0.5 pts)

### Ejercicio 4 — Quadratic equation solver (1.5 points)
Solve ax²+bx+c=0 using the quadratic formula, covering all three discriminant cases:
- Delta > 0: two real solutions
- Delta = 0: one double real solution
- Delta < 0: complex solutions (use `cmath`)
Award full marks if all three cases are correctly handled and outputs are shown.
Bonus: explaining how to access the real and imaginary parts of a complex number.

### Ejercicio 5 — Data structures (1.5 points)
- a) Justify using a dictionary to store book title → rating pairs (0.5 pts)
- b) Define a dictionary of at least 3 books with ratings and print name + rating for
  each element (1 pt)

### Ejercicio 6 — List operations (1 point)
Given `[15, 3, 45, 87, 1]`:
- a) Return the sorted list using `sorted()` (0.5 pts)
- b) Return the maximum and minimum values using `max()` and `min()` (0.5 pts)

### Ejercicio 7 — Debugging (1.5 points)
Fix the broken code and explain the solution:
  ```
  a = "Yann@Lecun"
  nombre = split(a,$)
  print(nombre)
  print(apellido)
  ```
Correct solution: `nombre, apellido = a.split('@')` — splitting on `@` and unpacking
into two variables. Award full marks if:
- The syntax error (`$`) is fixed
- `split` is called as a string method (`a.split(...)`) not a standalone function
- `apellido` is defined before being printed
- The student explains what was wrong

---

### Overall grading scale

10    — All 7 exercises fully correct with working code and outputs
8–9   — Minor issues in 1–2 exercises (small logic errors, missing output, style issues)
6–7   — Mostly correct; one exercise missing or substantially wrong
4–5   — About half the exercises correct; significant gaps in understanding
2–3   — Only 1–2 exercises correct; effort evident but major errors throughout
0–1   — Blank or near-blank submission; no meaningful attempt

### Notes
- Do not penalise `input()` calls for failing during automated execution — evaluate the
  written code's logic as-is (without running it) rather than the execution output
- Do not penalise generic or bare-bones `print` messages — only penalise if a message is
  clearly wrong, misleading, or fails to convey the requested information
- Shadowing built-in names (e.g. `list = [...]`) is a minor issue worth a small deduction
- Partial credit within exercises should be applied proportionally to the point values above
