Introducción a Python — Unidad 3: Ejercicios para entregar
Grading rubric (0–10 scale, total 10 points)

---

### Ejercicio 1 — Types and list filtering (1.5 points)
- a) Explains what the `for`/f-string loop over `lista` does and its output, correctly identifying each element's type (0.5 pts)
- b) Builds a new list with the elements of `lista` that are not strings (0.5 pts)
- c) Identifies integer elements and reports whether each is divisible by 2, printing an informative message per element (0.5 pts)

### Ejercicio 2 — List comprehensions (1 point)
- a) Builds a list containing only the booleans from `lista` (0.5 pts)
- b) Rebuilds the list replacing non-`int` elements with `nan` (0.5 pts)
Both parts MUST use a list comprehension — award no credit for an equivalent solved with an explicit `for` loop or `filter`/`map`.

### Ejercicio 3 — range, enumerate, dict + zip (1.5 points)
- a) Uses `range` to print odd numbers between 1 and 15 inclusive (0.5 pts)
- b) Function `elementos_pares()` that returns the elements at even *positions* (1-indexed) using `enumerate(..., start=1)` (0.5 pts)
- c) Defines a 4-item fruit→price dictionary and a matching purchased/not-purchased list, then builds one sentence per pair using `zip`/`dict.items()` (0.5 pts)

### Ejercicio 4 — Functions: acronym & reading planner (2 points)
- a) Function that returns the acronym of a given phrase, e.g. `"Comité Olímpico Internacional"` → `"COI"` (1 pt)
  Note: accept any reasonable implementation (case handling, accented letters, multiple spaces) — the exercise does not specify how to treat these, so do not penalise a sensible approach that differs from a literal reading.
- b) Function that, given a dict of book→pages, a reading pace (pages/day), and a number of available days, returns (and prints) the list of books readable in that time (1 pt)

### Ejercicio 5 — Tariff-band calculator, base logic (2 points)
- Defines the day-of-week and hour as two initial variables (0.5 pts)
- Determines whether the day is a weekday or weekend and identifies the correct tariff band for the given hour (1 pt)
- Prints a descriptive message naming the day, hour, and tariff band (0.5 pts)
**Important**: the exercise links to an external page for the exact valle/llana/punta hour ranges, which are not reproduced in the notebook. Do not penalise a student for using a different (but internally consistent and clearly stated) hour breakdown than yours — grade the *logic* (weekday/weekend split, correct comparison against their own stated ranges, correct message), not whether their hour boundaries match a specific external source.

### Ejercicio 6 — Wrap into a function with error handling (2 points)
- a.1) Function `calculadora_tramos_luz` takes day and hour as parameters (0.25 pts)
- a.2) Prints the tariff-band message and returns the band name (e.g. `"valle"`) (0.5 pts)
- a.3) Wraps the logic in try/except, handling all three error cases: invalid day name/typo, non-string day argument, and hour outside 0–23 (1 pt) — award partial credit per error case handled. If the error handling is incomplete or could be improved (e.g. missing a case, an overly broad/narrow `except`), do not deduct heavily — explain the gap and how to fix it, but apply only a small penalty. This does not apply to errors that break the notebook's execution or the exercise's core logic.
- b) Runs the four example cases from the table and shows each result (0.25 pts)

---

### Overall grading scale

10    — All 6 exercises fully correct with working code and outputs
8–9   — Minor issues in 1–2 exercises (small logic errors, missing output, style issues)
6–7   — Mostly correct; one exercise missing or substantially wrong
4–5   — About half the exercises correct; significant gaps in understanding
2–3   — Only 1–2 exercises correct; effort evident but major errors throughout
0–1   — Blank or near-blank submission; no meaningful attempt

### Notes
- Ejercicio 2 requires list comprehensions specifically; an otherwise-correct loop-based solution should lose the points for that sub-part.
- Ejercicio 4a (acronyms) and Ejercicio 5 (tariff hour ranges) are intentionally under-specified in the notebook — grade the underlying logic and give credit for any reasonable, internally consistent interpretation rather than requiring an exact match to one specific answer.
- Point values above were adjusted from the notebook's own in-cell labels so the rubric sums to exactly 10: Ejercicio 4b was reduced from 2 to 1 point, and the third sub-part of Ejercicio 5 was reduced from 1 to 0.5 points (the notebook's stated sub-part total for Ejercicio 5 was internally inconsistent — 2.5 vs. a stated 2-point exercise total).
- Partial credit within exercises should be applied proportionally to the point values above.
- Example print messages shown in the exercise statements are illustrative, not a required exact format. This applies to: Ejercicio 1c ("56 es divisible por 2"), Ejercicio 3c ("La fruta kiwi con precio 3€ se ha comprado? True"), Ejercicio 4b ("En 10 días puedo leer los libros siguientes: [...]"), Ejercicio 5/6 (tariff messages, e.g. "Lunes a las 10h: ..."), and the Ejercicio 6b example table. Award full credit as long as the student's message clearly conveys the same information — do not require matching wording, punctuation, or exact phrasing.
- Function names specified in the statement (e.g. `elementos_pares` in Ejercicio 3b, `calculadora_tramos_luz` in Ejercicio 6) are suggestions, not a grading criterion — do not penalise a student who uses a different name if the logic and behaviour are correct.
